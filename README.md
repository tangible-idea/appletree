# AppleTree

Mac의 파일과 폴더가 차지하는 공간을 시각적으로 보여주는 네이티브 SwiftUI 앱입니다. macOS 14 이상에서 실행됩니다. 용량 분석에는 외부 라이브러리나 서버 연결이 필요하지 않습니다. 선택 기능인 **알아서 정리**는 Mac에 설치된 Mole CLI를 사용합니다.

## 실행

```sh
bash scripts/build-app.sh
open dist/AppleTree.app
```

생성된 `dist/AppleTree.app`을 응용 프로그램 폴더로 복사해서 사용할 수 있습니다. Xcode 16 이상과 Swift 6 도구가 필요합니다. 개발 중에는 `swift run AppleTree` 또는 Xcode에서 `Package.swift`를 열어 실행하세요.

## 사용

앱은 실행할 때 macOS의 선호 언어 순서에 따라 **한국어 또는 영어**를 자동 선택합니다. 지원되는 언어가 없으면 영어를 사용합니다. macOS의 시스템 설정 → 일반 → 언어 및 지역 → 응용 프로그램에서 AppleTree의 언어만 따로 지정할 수도 있습니다. 언어 설정을 바꾼 뒤 앱을 다시 실행하면 적용됩니다. 실제 파일명과 폴더명은 원래 이름을 유지합니다.

- 처음에는 **미리보기**라고 표시된 샘플 데이터가 보입니다. **폴더 분석**(⌘O)으로 실제 폴더를 선택하세요.
- 왼쪽 바로가기로 홈, 다운로드, 데스크탑 등 자주 쓰는 폴더를 바로 분석할 수 있습니다.
- 용량 지도의 넓이는 해당 항목의 파일 크기에 비례합니다. 폴더를 더블 클릭하면 하위 폴더를 탐색합니다. 작은 항목은 ‘그 외’로 묶으며 더블 클릭하면 목록을 보여줍니다.
- 상단 경로 또는 ⌘[로 상위 폴더로 이동합니다. ⌘R은 전체 분석을 새로 실행합니다.
- **큰 파일**은 현재 폴더 아래의 모든 파일을 크기순으로 표시합니다. 검색도 현재 폴더 아래 전체 파일에 적용됩니다. 목록은 최대 200개씩 표시하며 검색으로 나머지 파일도 찾을 수 있습니다.
- **폴더별 보기**와 **큰 파일** 목록에는 수정일이 표시됩니다. 날짜에 마우스를 올리면 정확한 시간도 확인할 수 있습니다. 설정(⌘,) → **파일 목록에 수정일 표시**에서 날짜 열을 켜거나 끌 수 있으며, 선택은 즉시 적용되고 다음 실행에도 유지됩니다.
- 파일 작업 메뉴에서 열기, Finder에서 보기, 경로 복사, 휴지통으로 이동을 사용할 수 있습니다. 휴지통 이동은 확인 후 실행되며, 결과를 다시 분석합니다.
- 분석 중 취소하면 이전 결과가 유지됩니다. 접근할 수 없는 항목은 결과에서 제외하고 안내합니다.

## 알아서 정리

상단의 **알아서 정리**를 누르면 Mole의 `mo clean --dry-run`으로 후보를 찾고, 저장한 범위 안의 오래된 파일을 AppleTree가 정리합니다. Mole이 없으면 설치 명령 `brew install mole`을 안내합니다. `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`의 설치를 찾습니다.

- 처음에는 범위 설정을 보여주고 **설정 저장하고 정리**로 실행합니다. 이후 상단의 **알아서 정리**는 저장된 설정으로 바로 실행하고 진행 화면을 보여줍니다. **정리 내역 보기**에서는 실행 없이 결과와 설정을 확인할 수 있습니다. 설정 창에서도 범위와 보호할 폴더를 변경할 수 있습니다.
- 기본 범위는 사용자 `~/Library/Caches`의 7일 이상 변경되지 않은 파일과 사용자 로그·진단 폴더의 30일 이상 된 `log`, `crash`, `ips`, `diag` 파일입니다. npm·pip·Homebrew 다운로드·Yarn·Go 캐시는 별도로 활성화할 수 있습니다.
- 현재 탐색 중인 폴더와 관계없이 사용자 캐시·로그를 대상으로 합니다. 문서, 다운로드 원본, 휴지통 비우기, 앱 제거, 시스템 정리, 프로젝트 빌드 산출물 정리는 포함하지 않습니다. 관리자 권한을 요청하지 않습니다.
- AppleTree와 Mole의 데이터, 등록한 보호 폴더, Mole의 whitelist, 키·모델·데이터베이스·Git 데이터, 최근 파일, 확인된 사용 중인 앱·도구·파일을 제외합니다. 심볼릭 링크를 따라가지 않고 하드 링크 파일도 제외합니다. 삭제 직전에 파일 식별자·소유자·크기·변경 시각과 상위 경로를 다시 확인합니다.
- **정리 대상 파일은 휴지통을 거치지 않고 삭제합니다.** 캐시는 다음 실행에서 재생성·재다운로드가 필요할 수 있습니다. 탐색 또는 사용 상태 확인이 실패하면 파일을 삭제하지 않습니다.
- 진행 중 취소할 수 있습니다. 이미 정리한 파일은 결과와 기록에 남으며, 아직 처리하지 않은 파일은 유지합니다.
- 정리 후 측정한 후보의 범주별 전후 크기와 홈 디스크의 실제 여유 공간 변화를 따로 보여줍니다. 분석 캐시를 비우고 현재 용량 지도를 다시 분석합니다. 샘플 화면에서 시작했다면 사용자 `Library`를 분석합니다. 최근 정리 기록 10개는 `~/Library/Application Support/AppleTree/cleanup-history.json`에 저장합니다.

Mole의 텍스트 미리보기에서 실제 경로로 읽을 수 있는 후보만 사용합니다. 선택 범위는 캐시·로그 전체 탐색 결과가 아니라 Mole이 제시한 후보와 AppleTree 정책의 교집합입니다. 이번 버전은 버튼으로 실행하며 예약·백그라운드 자동 실행은 포함하지 않습니다.

## 용량 기준과 권한

파일 내용을 읽지 않고 메타데이터의 **논리적 파일 크기**를 합산합니다. 숨김 파일과 패키지 내부 파일을 포함하며, 심볼릭 링크는 따라가지 않습니다. 하드 링크는 경로별로 계산합니다. APFS 복제, 압축, 희소 파일, 클라우드 전용 파일 때문에 이 수치는 디스크의 실제 점유량이나 삭제 시 확보되는 공간과 다를 수 있습니다. 왼쪽 디스크 카드는 파일 시스템이 보고하는 전체/여유 공간을 별도로 표시합니다.

일부 보호된 폴더는 macOS의 권한 정책에 따라 읽을 수 없습니다. 필요한 경우 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한에서 AppleTree를 허용하고 다시 실행하세요. 앱이 자체적으로 권한을 변경하지는 않습니다.

빌드는 현재 Mac에서 실행할 수 있도록 ad-hoc 서명합니다. 다른 Mac에 배포하려면 Developer ID 서명 및 Apple 공증을 추가해야 합니다.

## 검증

```sh
swift test
swift run AppleTree --smoke-test
```

테스트는 실제 임시 폴더를 사용해 크기 합산, 정렬, 숨김 파일, 심볼릭 링크 순환, 빈 파일, 접근 오류, 취소를 검증합니다. 용량 지도는 면적 보존, 비율, 겹침, 경계 조건을 검증합니다.

`--smoke-test`는 개발 빌드에서 앱을 띄워 실제 폴더 분석, 탐색, 검색, 재분석, 취소, 오류 후 상태 보존을 확인하고 종료합니다. 정리 기능은 임시 홈 폴더와 테스트용 Mole 미리보기로 정리·보호·기록·지도 갱신을 검증하며 실제 사용자 파일은 정리하지 않습니다. `--snapshot /tmp/AppleTree.png`로 앱 창만 캡처할 수도 있습니다. `--cleanup-snapshot`을 함께 지정하면 범위 설정 화면, `--cleanup-result-snapshot`은 임시 파일로 만든 정리 결과 화면을 캡처합니다.

시스템 설정을 변경하지 않고 각 언어로 검증하려면 다음과 같이 실행하세요.

```sh
swift run AppleTree -AppleLanguages '(en)' --expect-language en --smoke-test
swift run AppleTree -AppleLanguages '(ko)' --expect-language ko --smoke-test
```

번역은 `Sources/AppleTreeCore/Resources/{en,ko}.lproj/Localizable.strings`에 있습니다. 앱 패키징 시 두 언어 리소스를 함께 복사합니다.

## 구조

- `Sources/AppleTreeCore`: 메타데이터 분석기, 파일 모델, treemap 알고리즘
- `Sources/AppleTree`: SwiftUI 화면, 비동기 상태 관리, Finder/휴지통 연동
- `scripts/build-app.sh`: 릴리스 빌드, 아이콘 생성, `.app` 패키징

CLI로 폴더를 지정해 실행할 수도 있습니다: `swift run AppleTree --scan /path/to/folder`.
